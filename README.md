# The Catholic Calendar

Find Catholic events, feast days, retreats, Masses, and parish activities near you.
Web app at [thecatholiccalendar.org](https://thecatholiccalendar.org), built with
React, Vite, Tailwind, and Supabase. The same codebase also ships as a native iOS
and Android app via [Capacitor](https://capacitorjs.com) — see
[`APP_STORE_GUIDE.md`](./APP_STORE_GUIDE.md) for everything involved in shipping
it to the App Store / Google Play, including push notification setup.

## Local development

```bash
npm install
cp .env.example .env   # fill in Supabase + Google Maps keys
npm run dev
```

## Building

```bash
npm run build           # web bundle -> dist/
npx cap sync             # copy it into ios/ and android/
npx cap open ios         # requires Xcode (macOS)
npx cap open android      # requires Android Studio
```

## Project layout

- `src/` — the React app (pages under `src/pages/calendar`, shared UI in
  `src/components`).
- `supabase/` — database migrations and edge functions.
- `ios/`, `android/` — native Capacitor projects. Generated by `npx cap add`, but
  committed: they hold hand-edited native config (permissions, push notification
  entitlements) that isn't regenerated by `cap sync`.
- `assets/` — source icon/splash images; `scripts/gen-app-assets.cjs` and
  `scripts/gen-pwa-icons.cjs` regenerate the platform-specific sizes from
  `src/assets/logo.png` if the logo ever changes.
